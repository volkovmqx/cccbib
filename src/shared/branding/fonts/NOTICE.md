# Bundled fonts

These fonts are bundled as Latin subsets and loaded only when selected in Settings.
The newer ones are static regular and bold files on purpose: variable fonts render with overlapping letters on webOS 5 (Chrome 68).
All fonts cover Latin Extended-A (Czech, Polish), except Silkscreen, which lacks most of those letters (they are drawn in the system font).
The pixel fonts, the monospaced fonts, Inclusive Sans, Fira Sans and Literata have no ligatures (the coding ligatures of Fira Code are left out on purpose). Tiny5, Pixelify Sans, Inclusive Sans, Literata, Atkinson Hyperlegible Next, Lexend, Open Sans and Fira Code are static instances cut from the variable sources at weights 400 and 700, and Inconsolata, Inter, Merriweather and Space Grotesk at weight 400 (Inter at optical size 14, Merriweather at 18, Literata at 12).
Each is licensed under the SIL Open Font License 1.1. The license texts are the `*-OFL.txt` files
next to the fonts (the text is identical, only the copyright line differs).
