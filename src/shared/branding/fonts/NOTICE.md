# Bundled fonts

These fonts are bundled as Latin subsets and loaded only when selected in Settings.
The newer ones are static regular and bold files on purpose: variable fonts render with overlapping letters on webOS 5 (Chrome 68).
The pixel fonts VT323, Jersey 10, Tiny5 and Geist Pixel and the monospaced IBM Plex Mono, Fira Code and Space Mono also cover Latin Extended-A (Czech, Polish) and have no ligatures (the coding ligatures of Fira Code are left out on purpose). Tiny5, Geist Pixel and Fira Code are static instances cut from the variable sources (Tiny5 and Fira Code at weights 400 and 700, Geist Pixel at the Square shape).
Each is licensed under the SIL Open Font License 1.1. The license texts are the `*-OFL.txt` files
next to the fonts (the text is identical, only the copyright line differs).
